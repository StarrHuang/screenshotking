# 截图与标注操作

默认流程：区域或窗口截图 → 自动复制图片并静默保存，不自动打开编辑器。保存到已设置的文件夹，未设置则使用 `~/Pictures/ScreenshotKing`。需要编辑时，在菜单栏插件点“编辑最近截图”，或打开截图库选择图片；也可在“设置 → 截图 → 截图后”切回“打开编辑器”。自动复制可关闭；标注后的结果需要再点复制来更新剪贴板。

进入编辑器后，顶部第二行可直接选择“备注”“步骤”“形状”“箭头”“文字”“高亮”“画笔”。右侧“样式参数”用于调整当前工具，或已选中对象的文字、颜色和格式。

- **备注**：点击图片放置输入框，输入说明，回车完成；双击已有备注修改。
- **步骤**：点击或拖动设置编号锚点与说明位置，再输入步骤说明；编号自动递增。“样式参数”内可切换一体和连线，以及说明框方向。
- **形状**：拖动绘制，可选8种形状和6种填充；双击可添加文字。
- **箭头**：拖动起点到终点，可选7种箭头/虚线样式。
- **画笔**：普通笔与荧光笔分别可选；高亮工具用于突出区域。
- **选择**：点击已有对象后拖动移动；可删除、复制；顶部撤销/重做恢复操作。
- **更多工具**：横向滚动工具栏可见马赛克、模糊、贴纸、放大镜和水印。固定右侧的样式入口不会随工具条滚走。
- **键盘与导航**：按住空格拖动平移画布，Shift绘制等比形状；“编辑 → 工具布局”可设置各工具单键。输入文字时不触发工具切换。屏幕阅读器可对备注、步骤、文字画布执行标准按下动作，在中心启动输入。
- **输出**：顶部复制、保存、分享、钉图保持可见。保存支持PNG/JPEG/HEIC；截图库的编辑源可再次打开修改。

需要选区旁直接标注时，先将“截图后”设为“打开编辑器”，再在“设置 → 截图”打开“选区内直接标注（浮引方式）”。它与独立窗口使用同一套工具。默认关闭，符合已确认的主流程。

功能实现、运行测试与原应用完全一致是不同结论。当前验证边界及未完成项见 [覆盖表](parity-matrix.md) 和 [验收记录](verification.md)。
