## 证据与方法

- `evidence/fuguang-info-plist.txt`：由 `plutil -p /Applications/浮引.app/Contents/Info.plist` 导出，确认 bundle 标识、版本与文档类型。
- `evidence/fuguang-source-sha256.txt`：原始可执行文件、中文本地化文件和 Info.plist 的 SHA-256，便于在同一安装版本复核。
- `evidence/fuguang-feature-localizations.tsv`：将 `zh-Hans.lproj/Localizable.strings`（UTF-16 XML plist）用 `plutil` 转成 binary plist 后，使用 Python `plistlib` 读取；按截图、剪贴板等关键词筛选 key/value，保留完整匹配文案。该提取覆盖 5,340 个本地化条目中的 848 个候选条目。
- `evidence/fuguang-feature-localizations-focused.tsv`：从上述候选中再按核心功能词过滤，方便逐项查阅。它不是新证据源，可能遗漏未命中关键词的相关文案。
- `evidence/fuguang-zh-complete-hits.txt`、`evidence/fuguang-zh-ui-hits.txt`：直接对原中文资源使用 `rg` 的宽/窄关键词命中结果，含原文件行号，可回查上下文。
- `evidence/fuguang-binary-strings.txt` 及 `evidence/fuguang-feature-symbol-hits.txt`：对主可执行文件运行 `strings -a` 并筛选功能词。`nm` 仅得到少量外部未定义符号及 Mach-O 头符号；应用本地符号表已剥离，`swift-demangle` 没有可解码的应用自有符号。因此**未获得可确认的 Swift 方法名**。`evidence/fuguang-demangled-symbols.txt` 与对应命中为空，记录了这一限制。
- `evidence/fuguang-info-plist.txt` 与 app 内 `PrivacyInfo.xcprivacy`：只用于识别声明项；声明不能证明运行时访问、网络传输或具体剪贴板处理方式。

证据等级：以下“静态候选”表示界面本地化文案或二进制中存在对应词项，可能是可选项、教程、错误提示或未启用功能；不等于功能可用、默认开启、特定版本/会员权限下可用，或实际按文案描述工作。本清单没有任何“实际行为已验证”项。
