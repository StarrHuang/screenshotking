## English

### Capture quietly. Edit when ready.

- A completed screenshot is saved silently and copied automatically. The editor, save dialog and Finder stay out of the way.
- Open **编辑最近截图** (Edit Recent Screenshot) from the menu bar or File menu, or pick an image from the library, to add notes and numbered steps when needed.
- Silent saves use your configured folder, or `~/Pictures/ScreenshotKing` if none is set. Existing filenames are not overwritten.
- The screenshot-frame and crown logo appears in the app and macOS icon. Other output modes remain available in Settings; an existing saved preference is preserved.

### More than a capture

The existing native editor includes notes, numbered steps with explanations, shapes, arrows, highlighter, pixelation/blur, crop, magnifier and watermarks. Local clipboard history supports rich formats, search, favorites, categories, tags and backups; monitoring starts off. Vision OCR, Apple Translation, scrolling capture and optional screen/system-audio recording share the native macOS stack. See the [feature and implementation overview](../../README.md).

### Install and verification

Requires **Apple Silicon and macOS 15+**. The ZIP is about **2.3 MiB**. Expand it and move `ScreenshotKing.app` to Applications. This is an **ad hoc signed, non-notarized development build**. Screen capture permission is required; automatic scrolling and active paste also require Accessibility permission. A rebuild/signature change may require permission renewal. Microphone and camera start off; iCloud sync is outside scope. The application interface is currently primarily Simplified Chinese; the documentation is bilingual.

Native build12 QA verified a 540×200 synthetic capture saved without an editor or restored app windows, and its clipboard image matched the file pixel for pixel. After restart, **File → 编辑最近截图** opened that image. The menu-bar entry shares the action but was not clicked in that QA run. Export regression/typecheck and strict signatures for the installed and unpacked ZIP passed. This release does not claim every recording path, scrolling page layout, cancellation race or reference-app interaction has been live-tested. Microphone/camera have not been live-tested. ## 简体中文

### 截图无感完成，需要时再编辑

- 截图完成后默认**静默保存并自动复制**，不弹编辑器、保存对话框或 Finder。
- 需要标注时，在菜单栏或“文件”菜单点击**编辑最近截图**，或从截图库选择图片，再添加备注和带说明的步骤。
- 自动保存沿用设置中的文件夹；未设置时使用 `~/Pictures/ScreenshotKing`，不覆盖同名文件。
- 截图框与皇冠 logo 用于应用界面和 macOS 图标。其他输出方式仍可在设置选择；用户已保存的选择会保留。

### 截图、标注与剪贴板的一套原生工具

既有编辑器包含备注、编号步骤说明、形状、箭头、荧光笔、像素化/模糊、裁剪、放大镜和水印。本地剪贴板支持多种富格式、搜索、收藏、分类、标签和备份，监听默认关闭。Vision OCR、Apple 翻译、长截图及可选的屏幕/系统音频录制使用原生 macOS 技术。详见[功能与实现介绍](../../README.zh-CN.md)。

### 安装与验证

需要 **Apple Silicon、macOS 15+**，ZIP 约 **2.3 MiB**。解压后将 `ScreenshotKing.app` 移入“应用程序”。这是 **ad hoc 签名、未经 Apple 公证的开发构建**。截图需要屏幕录制权限，自动滚动和主动粘贴还需要辅助功能权限；重建或换签名可能需要重新授权。麦克风/摄像头默认关闭，不提供 iCloud 同步。应用界面当前以简体中文为主，文档提供中英文。

build12 原生验收确认：540×200 合成截图静默保存，未弹编辑器或恢复旧窗口，剪贴板与文件逐像素一致；重启后通过“文件 → 编辑最近截图”打开同一图片。菜单栏入口使用同一动作，该次未实际点击。导出回归、类型检查、安装包及 ZIP 解压包严格签名校验通过。本版没有重新穷尽全部录屏路径、长页面布局、取消竞态或参考应用交互；麦克风/摄像头未实录验证。[验收记录](../verification.md) · [功能覆盖](../parity-matrix.md)。
