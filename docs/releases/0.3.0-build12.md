# ScreenshotKing 0.3.0 build12

原生 macOS 菜单栏截图、标注与本地剪贴板工具。

## 本版行为

- 截图后默认静默保存并自动复制，不自动打开编辑器、保存面板或 Finder。
- 需要标注时，从菜单栏“编辑最近截图”或截图库选择图片；文件菜单提供同一入口。
- 自动保存使用设置中的文件夹，未设置时使用 `~/Pictures/ScreenshotKing`，同名文件不会覆盖。
- 包含皇冠截图框 logo、备注、步骤等既有标注工具。
- 仍可在“设置 → 截图 → 截图后”选择打开编辑器等其他行为；已保存的用户选择会保留。

## 下载与要求

下载 Release 附件 `ScreenshotKing-0.3.0-build12-macOS-arm64.zip`，解压后将应用移至“应用程序”。仅支持 Apple Silicon、macOS 15 或更新版本。

这是 ad hoc 签名的开发构建，未进行 Apple 公证。首次截图需要屏幕录制权限；自动滚动和主动粘贴需要辅助功能权限。重建或更换签名后 macOS 可能要求重新授权。麦克风和摄像头默认关闭，iCloud 同步不在本项目范围内。

## 验证与边界

真实安装包从合成测试内容截取540×200图片，静默写入已配置文件夹，剪贴板图片与保存文件逐像素一致；完成后没有编辑器或其他自身窗口弹出。重启后通过“文件 → 编辑最近截图”打开同一图片通过。菜单栏入口使用同一动作，本轮未实际点击该入口。

导出回归与源码类型检查通过；安装包和 ZIP 解压包严格签名检查通过。本轮未重新验证全部长截图、全屏及取消竞态，也未测试麦克风或摄像头；不声称与参考应用所有功能和交互完全一致。详见[覆盖表](../parity-matrix.md)及[验收记录](../verification.md)。
