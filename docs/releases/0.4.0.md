# ScreenshotKing 0.4.0

**Quick screenshots. Rich annotations. Now in English and Simplified Chinese.**

[Apple Silicon ZIP](https://github.com/StarrHuang/screenshotking/releases/download/v0.4.0/ScreenshotKing-0.4.0-macOS-arm64.zip) · [SHA-256](https://github.com/StarrHuang/screenshotking/releases/download/v0.4.0/SHA256SUMS.txt) · [English README](../../README.md) · [Simplified Chinese](../../README.zh-CN.md)

## English

- **Follows your Mac’s language.** Menus, settings, capture controls, annotation editor, clipboard, recognition tools, errors and permission descriptions now support English and Simplified Chinese. Other preferred languages fall back to English. Relaunch ScreenshotKing after changing your macOS preferred language.
- **Capture and move on.** Screenshots still save silently, copy automatically and appear in a chronological local library. Open a capture when you want to edit.
- **Small app, rich annotations.** Notes and numbered steps with explanations and leader lines sit alongside arrows, shapes, highlighting, text, pixelation/blur, crop, stickers, magnification and watermarks. About **4.8 MiB installed**, **2.3 MiB ZIP**.
- **Your content stays yours.** Existing notes, document data, shortcuts, filenames and clipboard contents keep their original text. The English README now shows the actual English editor on synthetic content.

Requires **Apple Silicon and macOS 15+**. Move the expanded app to Applications. Build 13 is ad hoc signed and **not notarized by Apple**. Screen capture permission is required; Accessibility is required for automatic scrolling and active paste. Microphone/camera remain off by default and were not live-tested. No iCloud sync.

Verification: all 508 translation keys, language selection (English, Simplified Chinese, and English fallback), substitutions and permission descriptions passed runtime tests. Geometry, exports, private clipboard, image editing/recovery and recognition tests passed. Installed native English and Chinese interfaces were checked, including actual note entry and step controls. A real 520×450 synthetic capture saved automatically and matched its clipboard image pixel for pixel. Built, installed and unpacked apps matched, with strict signature checks. See [verification](../verification.md) and [coverage](../parity-matrix.md) for limits.

## 简体中文

- **界面自动跟随系统语言。** 菜单、设置、截图控件、标注编辑器、剪贴板、识别工具、错误和权限说明均提供中英文；其他语言回退英文。更改 macOS 首选语言后重新打开应用即可。
- **截图快，自动归档。** 默认仍是静默保存、自动复制，并进入按时间排序的本地截图库；需要时再打开编辑。
- **体积轻，标注不精简。** 备注、带说明和引线的编号步骤，加上箭头、形状、高亮、文字、像素化/模糊、裁剪、贴纸、放大镜和水印。安装后约 **4.8 MiB**，下载约 **2.3 MiB**。
- **已有内容保留原文。** 备注、文档、快捷键、文件名和剪贴内容不会被翻译或重写。英文 README 已换用真实英文编辑器窗口和合成内容。

需要 **Apple Silicon、macOS 15+**。解压后将应用移入“应用程序”。build13 使用 ad hoc 签名，**未经 Apple 公证**。截图需要屏幕录制权限，自动滚动和主动粘贴需要辅助功能权限。麦克风和摄像头默认关闭，本次未实录测试；不提供 iCloud 同步。
