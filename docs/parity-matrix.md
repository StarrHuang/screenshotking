# ScreenshotKing 覆盖表

范围：截图后静默保存并自动复制为默认，菜单栏手动进入编辑；独立编辑窗口和浮引式选区内标注可选；录屏按需；iCloud 同步按用户决定排除。

本表区分三个层次：观察到原应用入口；自有实现存在；运行验证通过。前两者不等于已实现完全兼容。浮引实际参数见 `fuguang-ui-observations.md`；静态候选见 `fuguang-tool-parameters.md`。
